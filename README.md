# SSAFY 코딩테스트 스터디

> [프로그래머스 코딩테스트 고득점 Kit](https://school.programmers.co.kr/learn/challenges?tab=algorithm_practice_kit) 10개 유형을 10주간 완주합니다.

## 📋 스터디 정보

- **기간**: 10주 (1주 1개 유형)
- **문제**: 고득점 Kit 전체 **47문제**
- **스터디원**: 오명헌, 정호성, 김은혜, 김소영, 곽지영 (5명)
- **진행 방식**:
  1. 개인 fork 레포에서 문제 풀이
  2. 매주 해당 유형의 문제를 모두 풀어서 커밋
  3. 일주일에 1회 메인 레포에 PR 제출
